# 验收标准

## Gate 0：项目与数据源边界

- [ ] ETF候选池、跟踪指数、上市日期及产品信息可追溯。
- [ ] free-stockdb 用户 fork 的真实接口、字段、数据源配置和本地数据范围已核验。
- [ ] 数据授权及使用限制已记录。
- [ ] 原始行情和本地快照未被提交到GitHub。

## Gate 1：数据适配与审计

- [ ] 五只ETF逐只输出覆盖范围与数据质量报告。
- [ ] 交易日、停牌、未上市、退市状态可区分。
- [ ] 原始价格、复权因子、分红语义明确且可复现。
- [ ] OHLC、成交量、成交额及重复/缺失检查通过。
- [ ] 数据来源、版本、获取时间和快照标识可追溯。
- [ ] 组合共同区间由真实有效数据计算，而非硬编码。

## Gate 2：历史指数成分与暴露

- [ ] 能按生效日期重建历史指数成分。
- [ ] 历史权重可得时完成权重穿透；不可得时明确降级。
- [ ] 当前成分未被回填为历史成分。
- [ ] 输出成分重叠、行业暴露、风格暴露和历史变化报告。
- [ ] 510300、510880、513020、159928、159611之间的重复暴露有证据说明。

## Gate 3：回测引擎与账本

- [ ] 信号日期与成交日期严格分离，无未来函数。
- [ ] 所有策略共用成交引擎、费用模型、现金池和持仓账本。
- [ ] 现金、份额、费用、分红逐笔守恒。
- [ ] 停牌、无成交、最小交易单位、涨跌停和异常报价有测试。
- [ ] 分红不会在复权收益与现金账本中重复计入。
- [ ] 同一配置和数据快照可复现相同结果。

## Gate 4：策略对比

- [ ] A/B/C/D在一致条件下比较。
- [ ] A/B/C/D共用同一执行引擎和账本；A/B/C按单ETF独立比较，D使用多ETF公共资金池。
- [ ] 分红或执行规则状态非PASS时，正式运行被阻断；研究性运行必须显式标记 research_only。
- [ ] 买入档位和卖出状态机有单元测试及边界测试。
- [ ] 公共资金池约束和现金保留规则有测试。
- [ ] 滚动区间、市场阶段和参数敏感性分析完成。
- [ ] 报告同时呈现累计份额、成本、现金占用、回撤、费用和总资产。
- [ ] 513020的折溢价与跨市场交易日限制单独披露。

## 失败处理

任何 Gate 未通过，相关后续结论标记为 `BLOCKED`，并记录具体缺失、证据、影响和解除条件。不得通过跳过测试、伪造数据或把模拟结果标为真实结果来满足验收。
