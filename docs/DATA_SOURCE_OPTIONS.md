# 外部历史数据源候选与取舍

本文件记录公开资料检索得到的候选来源。它们不是已经接入或授权的数据源；正式使用前必须核验访问权限、历史覆盖、字段口径、费用和再分发条款。

## 1. 指数历史成分与权重

### 首选核验对象：中证指数官方授权数据

中国投资信息有限公司（CIIS）介绍的中证指数基本面数据包含：
- 成分与权重：当日收盘权重、次日开盘权重、拟纳入证券；
- 公司行为事件：包括分红、股权变动、增发等；
- 指数除数的每日变化。

其说明数据需取得中证指数基本面数据许可，之后通过CIIS SFTP、CSI或授权信息服务商访问。该来源在字段和数据血缘上最接近本项目所需的点时历史数据，但不是已确认的免费数据源。

参考：https://www.ciis.com.hk/hongkong/sc/idata/csifundamentaldata/index.shtml

### 上证红利指数

上交所公开指数页面和指数编制方案可用于核验指数定义、调整公告及规则；但公开页面可见当前指数信息，不等于已经提供完整的历史成分权重文件。历史成分应按官方调整公告还原；如果无法取得生效日期和历史权重，报告必须降级为成分集合重叠。

参考：
- 上交所指数体系：https://www.sse.com.cn/market/sseindex/overview/
- 上证红利指数编制方案：https://www.sse.com.cn/market/sseindex/indexlist/indexdetails/indexmethods/c1/000015_000015hbook_CN.pdf

### 第三方历史数据服务

第三方服务页面可作为候选线索，但需验证授权、覆盖起始日、权重更新频率和历史调整时点。不得因页面宣称有历史成分，就假定所有五个跟踪指数都覆盖。

## 2. ETF自身分红事件

分红数据应以基金管理人正式公告为首选依据。至少提取：

- 基金代码；
- 公告日；
- 收益分配基准日；
- 权益登记日；
- 除息日；
- 现金发放日；
- 每份或每10份现金分红金额；
- 现金分红/红利再投资方式；
- 原始公告链接、文件哈希和获取时间。

### 官方公告示例

上交所披露的510880分红公告列出了基金代码、每10份分红金额、登记日、除息日和现金红利发放日，证明正式公告可提供账本所需的核心字段。应按同样口径逐只ETF收集，不能把其他基金的公告或指数成分股分红当作ETF份额分红。

参考：https://www.sse.com.cn/disclosure/fund/announcement/c/new/2026-01-16/510880_20260116_DSHH.pdf

### 可用的辅助聚合源

- 理杏仁基金分红API：提供登记日、除息日和每份分红金额；需要用户Token，单次查询时间跨度最多10年。访问条款和费用需确认。https://www.lixinger.com/api/open-api/html-doc/cn/fund/dividend
- CnOpenData公募基金分红数据：公开说明列出公告日、登记日、除息日、派息日、每份派息金额等字段，页面标注数据覆盖至2025-07-01并需订阅/下载权限。https://www.cnopendata.com/data/m/recent/fund-dividends.html
- 天天基金等行情聚合页面可用于交叉核对，不作为唯一权威来源。

## 3. 数据接入决策

| 数据类别 | 首选路径 | 备用路径 | 未取得时的处理 |
|---|---|---|---|
| ETF日行情 | 已审计的free-stockdb本地数据 | 其他可追溯行情源 | MISSING，阻断对应回测 |
| 复权因子 | 源数据因子 + 独立价格核对 | 其他供应商复权序列交叉验证 | UNKNOWN，不生成正式指标序列 |
| ETF份额分红 | 基金管理人/交易所正式公告 | 有授权的基金分红API | MISSING，不能把复权价收益冒充现金分红 |
| 中证指数历史成分/权重 | 中证指数授权数据 | 可验证的官方调整公告档案 | 无权重则仅报告集合重叠；无历史成分则MISSING |
| 上证红利历史成分/权重 | 上交所指数官方公告/授权数据 | 可验证的历史公告档案 | 无权重则降级，不得用当前权重回填 |

## 4. 重要口径区分

1. ETF自身份额分红与指数成分股公司分红是两种不同事件。
2. 指数历史成分、指数历史权重、ETF实际持仓披露不可互相替代。
3. 基金分红公告中的“每10份分红”必须换算成每份金额，且保留原始金额和换算公式。
4. 复权价格可用于连续收益/指标序列，但不能代替现金分红账本。
5. 当前成分、当前行业映射、当前权重不能回填历史。
6. 来源网站可访问不代表允许批量抓取、商业使用或再分发。

## 5. 当前结论

- 免费且可直接覆盖五只ETF的完整历史成分、权重、分红数据源：尚未确认。
- 最可信的完整指数历史数据路径是核验中证指数授权数据的许可和费用。
- 低成本替代方案是从官方调整公告构建历史成分集合，并对无法取得的历史权重明确降级；这不能满足完整权重穿透的验收条件。
- ETF分红优先从基金管理人/交易所公告逐只采集，再用第三方数据交叉核对。
