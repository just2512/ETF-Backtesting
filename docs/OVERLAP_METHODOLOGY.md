# 指数成分与组合暴露重叠方法

## 1. 目的

确认不同ETF是否真正提供不同风险暴露，避免仅按产品名称判断分散化。重点检查历史成分、行业、风格和时间变化。

## 2. 数据口径必须分开

以下数据不可混为一谈：

1. 跟踪指数的历史成分与权重；
2. ETF定期报告披露的实际持仓；
3. 第三方当前行业分类或当前成分快照。

指数权重可用于重建指数层面的穿透暴露；ETF实际持仓用于核对跟踪偏离及现金/抽样差异。当前快照不能替代历史数据。

## 3. 四层分析

### A. 成分股集合重叠

对每个历史观察日或指数调整生效日，计算两指数成分集合交集、并集及覆盖比例。报告必须注明使用的是成分数量还是权重口径。

### B. 权重重叠

若历史权重可得，对证券i计算：

`Overlap(A,B) = sum_i min(w_{A,i}, w_{B,i})`

权重需先统一为小数并校验指数权重合计。权重缺失或口径不一致时不得计算该指标。

### C. 行业与风格暴露

行业分类必须注明分类体系、版本和生效日期。风格维度至少区分宽基、红利/价值、成长/科技、消费、公用事业等；风格标签是研究分类，不应冒充官方指数分类。

### D. 历史滚动变化

在历史成分调整日或固定观察频率上重算，展示重叠关系如何变化。不得仅用当前成分解释整个历史回测。

## 4. 组合穿透权重

若ETF j 在组合中的资金权重为 A_j，ETF j 对证券 i 的指数权重为 W_{j,i}，则：

`W_portfolio,i = sum_j (A_j * W_{j,i})`

前提是ETF资金权重和指数成分权重使用同一估值时点，且指数权重可得。若使用ETF实际持仓，需另行说明披露日期与滞后。

## 5. 输出

- `latest_constituent_overlap.csv`
- `historical_constituent_overlap.csv`
- `industry_exposure.csv`
- `style_exposure.csv`
- `top_duplicate_holdings.csv`
- `overlap_review.md`

## 6. 解释限制

- 510300本身包含金融、消费、电力等行业暴露。
- 510880不能简单视为低风险资产，其行业权重可能集中于金融、能源等周期板块。
- 513020存在跨市场、汇率和估值时差风险。
- 159928代表中证主要消费口径，不等于覆盖全部可选消费。
- 电力ETF具有行业集中属性，需与红利ETF及宽基做历史穿透比较。

以上为审查假设，最终结论必须由指定日期的真实数据支持。
