# 回测方法与策略定义

## 1. 回测比较组

- **A 固定定投**：固定周期、固定金额买入，不主动卖出。
- **B 布林积累**：布林下轨分批买入，不主动卖出。此组直接检验低位积累是否优于固定定投。
- **C 布林买卖**：下轨分批买入，上轨触发分批卖出。
- **D 公共资金池动态分配**：多ETF共享现金池，按信号强度与组合约束分配资金，并保留长期底仓。

各策略必须在相同数据区间、初始资金、外部追加资金、费用、成交规则和交易日历下比较。

## 2. 布林指标与信号时序

首轮参数基线：

- 中轨：20日简单移动平均；
- 标准差：20日窗口，采用总体标准差（ddof=0），并在配置中显式记录；
- 上下轨：中轨 ± 2倍标准差；
- `%B = (close - lower) / (upper - lower)`。

信号在交易日收盘后计算，最早在下一交易日执行。严禁用当日收盘价生成信号后，又假设以同一收盘价成交。

指标价格序列必须正确处理分红等公司行为；成交价格和账户估值使用原始市场价格。只有复权因子语义经过独立验证后，才允许使用供应商前复权收盘价生成指标；复权语义未知时阻断正式指标回测。

## 3. 下轨分批买入实验档位

初始待检验规则（比例按单只ETF预设额度计算，而非公共现金总额）：

| 触发条件 | 单档目标额度 |
|---|---:|
| %B ≤ 0 | 20% |
| %B ≤ -0.10 | 20% |
| %B ≤ -0.20 | 25% |
| %B ≤ -0.30 | 35% |

这是实验基线，不是已证明的最优参数。每个档位在一个买入周期内只触发一次；连续处于下轨以下不重复触发。收盘回到中轨上方后结束本轮买入周期，之后再次跌破下轨才开启新周期。

若单日跳空越过多个档位，需按预先声明的规则处理，不能假设按未实际触及的档位价格成交。

## 4. 卖出对照

- **S0**：不主动卖出。
- **S1**：首次有效突破上轨后，卖出当前持仓的一部分（实验起点20%）。
- **S2**：首次突破上轨后等待重新进入通道（%B<1），卖出当前持仓10%；随后回落至中轨（%B≤0.5）再卖出当前持仓10%。两次卖出均按触发时的剩余持仓计算。比例可配置，首轮基线为10%+10%。

卖出事件必须有状态机防重复；卖出资金回公共现金池。S1在重新进入通道后允许下一轮新的上轨突破触发；S2完成第二次卖出后结束本轮。必须报告卖出后继续上涨幅度、减少的持仓份额及对长期累计份额的影响。不得默认突破上轨即清仓。

## 5. 公共资金池与组合约束

各ETF独立持仓账本，共享现金池。每次分配前依次检查：

1. 数据与信号有效；
2. 单只ETF持仓上限；
3. 行业/指数穿透暴露约束；
4. 最低现金储备；
5. 买入信号优先级；
6. 可成交数量、最小交易单位、停牌/涨跌停和费用。
7. 若启用行业暴露上限，必须使用对应日期有效的指数成分权重和行业分类；缺少穿透数据时阻断该项分配，不得忽略未知证券。

偏离布林下轨的程度可作为信号排序依据，但排序公式须显式定义并进行敏感性分析。不得因多只ETF同时触发买入而自动耗尽现金。

初始资金、追加资金、单只上限、最低现金储备等尚未确认的参数应配置为待填写项，不得擅自假设为用户真实资金计划。

## 6. 成交与费用

- 收盘后生成信号，下一交易日执行。
- 使用可成交市场价格；停牌或无有效报价时不成交。
- 明确最小交易单位、涨跌停限制、滑点和买卖价差处理。
- 费用参数可先配置为佣金0.015%、其他费用0.004%的研究初值，但须核验券商最低收费、ETF适用规则及各项费用是否重复计算。
- 对513020单独处理折溢价、跨市场交易日、估值时间差和流动性；不得把指数价格当作ETF成交价。

## 7. 账本守恒

每笔交易必须记录：时间、证券、方向、数量、成交价、成交额、费用、成交后现金、成交后持仓、信号来源。

现金变动、份额变动、费用和分红必须可逐笔重算。ETF分红按登记日收盘持有份额确定权益，在派息日将每份现金分红计入现金账本；除息日价格使用原始行情，不再额外叠加复权收益。期末总资产按持仓市值加现金计算，并清晰说明估值价格口径。

## 8. 必须报告的指标

- 累计外部投入；
- 期末现金、期末持仓份额及持仓市值；
- 平均买入价与剩余持仓成本（两者定义不可混用）；
- 分红收入及处理方式；
- 最大资金占用、最大浮亏、最大回撤；
- 交易次数、换手、费用、滑点；
- 卖出后价格继续上涨幅度；
- 期末总资产及按外部现金流计算的收益指标。

不能只看净值曲线或单一收益率。定期外部投入必须从账户价值序列中剥离，先按明确的现金流时点（期初或期末）计算单位净值，再计算最大回撤；不得把新增本金误认为投资收益。回测运行器对持仓证券在无当日行情时使用最近可用收盘价估值，同时必须标记该证券为stale，不得把陈旧价格误认为当日成交价。长期积累策略还要比较累计持有份额、现金占用和回撤。

## 9. 稳健性验证

采用滚动区间、不同市场阶段和参数敏感性分析。参数选择与最终评估区间必须隔离，防止过拟合。对交易成本、滑点、现金储备和ETF池变化做压力测试。

正式回测必须使用审计通过的数据快照；任何关键数据缺失均需停止对应实验或降级结论。
