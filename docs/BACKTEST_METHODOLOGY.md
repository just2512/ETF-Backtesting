# 回测方法与策略定义

## 1. 回测比较组

- **A 固定定投**：固定周期、固定金额买入，不主动卖出。
- **B 布林积累**：布林下轨分批买入，不主动卖出。此组直接检验低位积累是否优于固定定投。
- **C 布林买卖**：下轨分批买入，上轨触发分批卖出。
- **D 公共资金池动态分配**：多ETF共享现金池，按信号强度与组合约束分配资金，并保留长期底仓。

各策略必须在相同数据区间、初始资金、外部追加资金、费用、成交规则和交易日历下比较。

## 2. 布林指标与信号时序

首轮参数基线：

- 中轨：20日简单移动平均；
- 标准差：20日窗口，采用总体标准差（ddof=0），并在配置中显式记录；
- 上下轨：中轨 ± 2倍标准差；
- `%B = (close - lower) / (upper - lower)`。

信号在交易日收盘后计算，最早在下一交易日执行。严禁用当日收盘价生成信号后，又假设以同一收盘价成交。

指标价格序列必须正确处理分红等公司行为；成交价格和账户估值使用原始市场价格。只有复权因子语义经过独立验证后，才允许使用供应商前复权收盘价生成指标；复权语义未知时阻断正式指标回测。

## 3. 下轨分批买入实验档位

初始待检验规则（比例按单只ETF预设额度计算，而非公共现金总额）：

| 触发条件 | 单档目标额度 |
|---|---:|
| %B ≤ 0 | 20% |
| %B ≤ -0.10 | 20% |
| %B ≤ -0.20 | 25% |
| %B ≤ -0.30 | 35% |

这是实验基线，不是已证明的最优参数。每个档位在一个买入周期内只触发一次；连续处于下轨以下不重复触发。收盘回到中轨上方后结束本轮买入周期，之后再次跌破下轨才开启新周期。

若单日跳空越过多个档位，需按预先声明的规则处理，不能假设按未实际触及的档位价格成交。

## 4. 卖出对照

- **S0**：不主动卖出。
- **S1**：首次有效突破上轨后，卖出当前持仓的一部分（实验起点20%）。
- **S2**：首次突破上轨后等待重新进入通道（%B<1），卖出当前持仓10%；随后回落至中轨（%B≤0.5）再卖出当前持仓10%。两次卖出均按触发时的剩余持仓计算。比例可配置，首轮基线为10%+10%。

卖出事件必须有状态机防重复；卖出资金回公共现金池。S1在重新进入通道后允许下一轮新的上轨突破触发；S2完成第二次卖出后结束本轮。必须报告卖出后继续上涨幅度、减少的持仓份额及对长期累计份额的影响。不得默认突破上轨即清仓。

## 5. 公共资金池与组合约束

各ETF独立持仓账本，共享现金池。每次分配前依次检查：

1. 数据与信号有效；
2. 单只ETF持仓上限；
3. 行业/指数穿透暴露约束；
4. 最低现金储备；
5. 买入信号优先级；
6. 可成交数量、最小交易单位、停牌/涨跌停和费用。
7. 若启用行业暴露上限，必须使用对应日期有效的指数成分权重和行业分类；缺少穿透数据时阻断该项分配，不得忽略未知证券。

偏离布林下轨的程度可作为信号排序依据，但排序公式须显式定义并进行敏感性分析。不得因多只ETF同时触发买入而自动耗尽现金。

初始资金、追加资金、单只上限、最低现金储备等尚未确认的参数应配置为待填写项，不得擅自假设为用户真实资金计划。

## 6. 成交与费用

- 收盘后生成信号，下一交易日执行。
- 使用可成交市场价格；停牌或无有效报价时不成交。
- 明确最小交易单位、涨跌停限制、滑点和买卖价差处理。
- 费用参数可先配置为佣金0.015%、其他费用0.004%的研究初值，但须核验券商最低收费、ETF适用规则及各项费用是否重复计算。
- 对513020单独处理折溢价、跨市场交易日、估值时间差和流动性；不得把指数价格当作ETF成交价。

## 7. 账本守恒

每笔交易必须记录：时间、证券、方向、数量、成交价、成交额、费用、成交后现金、成交后持仓、信号来源。

现金变动、份额变动、费用和分红必须可逐笔重算。ETF分红按登记日收盘持有份额确定权益，在派息日将每份现金分红计入现金账本；除息日价格使用原始行情，不再额外叠加复权收益。期末总资产按持仓市值加现金计算，并清晰说明估值价格口径。

## 8. 必须报告的指标

- 累计外部投入；
- 期末现金、期末持仓份额及持仓市值；
- 平均买入价与剩余持仓成本（两者定义不可混用）；
- 分红收入及处理方式；
- 最大资金占用、最大浮亏、最大回撤；
- 交易次数、换手、费用、滑点；
- 卖出后价格继续上涨幅度；
- 期末总资产及按外部现金流计算的收益指标。

不能只看净值曲线或单一收益率。定期外部投入必须从账户价值序列中剥离，先按明确的现金流时点（期初或期末）计算单位净值，再计算最大回撤；不得把新增本金误认为投资收益。回测运行器对持仓证券在无当日行情时使用最近可用收盘价估值，同时必须标记该证券为stale，不得把陈旧价格误认为当日成交价。长期积累策略还要比较累计持有份额、现金占用和回撤。

## 9. 稳健性验证

采用滚动区间、不同市场阶段和参数敏感性分析。参数选择与最终评估区间必须隔离，防止过拟合。对交易成本、滑点、现金储备和ETF池变化做压力测试。

正式回测必须使用审计通过的数据快照；任何关键数据缺失均需停止对应实验或降级结论。


## 10. A/B/C/D统一执行接口

代码入口为 `StrategyBacktestRunner`。四组策略不再各自执行买卖或维护账本，而由 `StrategySignalOrchestrator` 生成下一交易日订单，并统一交给 `PortfolioBacktestRunner`。

- A/B/C按单只ETF分别运行，输出可逐只比较的固定定投、布林积累和布林买卖结果。
- D可同时输入多只ETF；同日买入信号按%B从低到高、证券代码作为稳定次序，经公共现金池分配，并执行最低现金储备和单只市值上限。
- 启用行业约束时，必须注入对应信号日可用的 `IndustryExposureContext` 提供器；不能提供历史穿透数据则阻断分配。
- A/B/C/D都必须传入相同口径的初始资金、交易日历、追加资金、成本模型和数据快照，比较时不得使用各自不同的回测日期轴。
- 当分红或成交规则状态不是 PASS 时，正式运行会 fail-closed。研究性机制验证可显式设置 `research_only=True`，其输出不得标记为正式回测。
- `per_etf_cycle_budget`、`dca_budget_by_symbol`、D策略的单只ETF市值上限与现金储备均为外部显式参数；配置未确认时不推测用户资金计划。


## 11. 真实成交约束

`ExecutionMarketContext` 是每个证券/交易日的 point-in-time 执行上下文，至少包含 bid/ask、limit_up/limit_down、suspended、upper_limit_locked、lower_limit_locked。正式成交不再把 OHLC open 当作无条件可成交价。

`ExecutionModel` 显式设置 slippage_bps、market_impact_bps 和 max_spread_bps。买单以 ask 为基准，卖单以 bid 为基准，叠加不利滑点与冲击；价差超过上限或冲击后越过涨跌停价时不成交。上下文缺失、停牌状态未知、报价缺失、涨跌停状态缺失均不得默认为可交易。

订单在信号日以收盘价编译，次日以实际 quote 执行。如果开盘价格和费用导致原始数量超出订单分配额度或最低现金储备，执行引擎按整手计算最大可负担数量，记录 PARTIAL；不足一手则拒单。成交结果保留 requested_quantity 与实际 quantity，报告区分全额和部分成交。

`config/execution_model.yaml` 不预填滑点、冲击或价差假设。没有历史 bid/ask、限价/封板状态和经确认的执行假设时，正式回测必须 BLOCKED；研究性实验可显式 `research_only=True`，但不得标记为正式结果。


## 12. ETF现金分红事件完整性

现金分红事件必须从基金管理人/交易所官方公告导入，包含证券代码、除息日、权益登记日、派息日、每份现金分红、公告日期、来源名称和公告URL。每只ETF还必须有覆盖声明，证明官方来源覆盖本次回测完整区间。

分红事件文件与覆盖文件共同计算SHA-256。正式回测必须传入该哈希，且每条事件都必须保留公告来源。事件公告日期不得晚于除息日，避免将未来公告信息回填到过去。对没有分红事件的证券，只有完整覆盖证明才能判定区间内未发现事件；没有覆盖声明一律 UNKNOWN，不得默认为零分红。
